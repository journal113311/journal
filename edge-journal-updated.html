Opening-location rule reminder

If NQ opens OUTSIDE yesterday's value area (above VAH or below VAL), treat the market as being in IMBALANCE. Do not try to catch the top or bottom, and do not fade the move just because price looks extended. Avoid predicting where the move will end. Wait for your planned setup and confirmation, manage risk, and let price action show whether the imbalance is continuing or failing.

Google Drive backup

Keeps an extra copy of your journal — including screenshots — as one file in your own Google Drive, on top of the local copy in this browser. Local storage stays the primary copy; Drive is a safety net in case this device is lost, reset, or you switch computers.

One-time setup (do this once, in Google Cloud Console)
  1. Go to console.cloud.google.com and create a project (or pick an existing one).
  2. APIs & Services → Library → search for and enable Google Drive API.
  3. APIs & Services → OAuth consent screen → choose External → fill in the basic app info → under Test users, add your own Google account. (In testing mode no Google review is needed, since only you can sign in.)
  4. APIs & Services → Credentials → Create Credentials → OAuth client ID → Application type Web application.
  5. Under Authorized JavaScript origins, add the exact web address you'll open this journal from (e.g. https://yourname.github.io) — opening the file by double-clicking it (file://…) will not work; it has to be served from a real address. Free options: GitHub Pages or Netlify.
  6. Click Create, then copy the Client ID it gives you.
  7. Open this HTML file in a text editor, find GOOGLE_CLIENT_ID = '' near the top of the <script> section, and paste your Client ID between the quotes.
  8. Upload the file to your hosting (GitHub Pages / Netlify) and open it from that address. The Client ID is safe to leave in the file — it's a public identifier, not a secret.

Local storage & backups

Your journal stays in this browser on this computer. It does not sync to a server. Clearing browser data can erase it, so export backups regularly.

How to use

  1. Open the calendar and select a date.
  2. Complete the premarket plan before your session. Save partial notes whenever you like.
  3. During trading, add time-stamped observations and record decisions, including no-trade decisions.
  4. Add each execution as a trade card: enter net P&L and initial risk to calculate net R automatically, optionally mark a 50% partial at 2R, and upload chart screenshots for a large preview.
  5. Finish the postmarket review and mark the day Reviewed or No trade.
  6. Export a JSON backup periodically and keep it somewhere safe.
